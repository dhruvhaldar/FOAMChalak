## 2025-02-18 - Keyboard Accessibility for Table Row Accordions
**Learning:** Dynamically generated `<tr>` elements used as accordions in this app completely lack keyboard navigation. Screen reader users and keyboard-only users cannot expand run history details because the rows do not receive focus, lack a defined `role="button"`, and don't listen for keyboard events (Enter/Space) to trigger the `onclick` handler. Furthermore, there is no `aria-expanded` state.
**Action:** When converting generic elements like `<div>` or `<tr>` into interactive components, always manually apply `tabindex="0"`, `role="button"`, `aria-expanded`, and add an `onkeydown` handler to intercept `Enter` and `Space` to simulate clicks. Ensure the `aria-expanded` state syncs with the visibility of the controlled content.
